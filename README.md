# TaskNest

## Overview
TaskNest is a web-based task management application designed to help users organize and track their daily tasks with ease. It provides a simple and intuitive interface for managing productivity through task creation, tracking, and completion.

## Features
- **User Authentication**: Sign up and log in securely to manage personal tasks
- **Task Management**: Add, complete, and delete tasks effortlessly
- **Task Filtering**: View all tasks, active tasks, or completed tasks
- **Task Statistics**: Track total tasks and completion progress
- **Clear Completed**: Bulk clear all completed tasks with one click
- **Responsive Design**: Works seamlessly across desktop and mobile devices

## Pages
- **Homepage** (`index.html`): Landing page with project introduction
- **Login** (`tasknest_loginpage/`): User authentication login page
- **Signup** (`tasknest_signuppage/`): New user registration page
- **Task Manager** (`tasknest_manager/`): Main application interface for task management

## Technology Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Getting Started
1. Open `index.html` or https://task-nest-rho-ten.vercel.app/ in your web browser
2. Sign up for a new account or log in with existing credentials
3. Start managing your tasks in the Task Manager interface
